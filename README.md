One word for the whole internet: **funhouse** — a hall of distorted mirrors where everything is loud, warped, a little scary, and impossible to walk out of. That is the internet: every feed a new corridor, every reflection slightly wrong, and everyone still laughing on the way through.

## Run it

```sh
node main.ts
```

Writes `funhouse` to `/output/entry.txt` (8 bytes, one word).
